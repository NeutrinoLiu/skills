bangya-poster pipeline

How a paper becomes a print-ready poster. The sheet is one HTML file at 1 CSS px = 1 mm; PLACEHOLDERS.md is the canvas; feedback_N.md carries each round — chat stays terse ("continue", "go do all the rest").

Main session · design & build

1Brief

Paper source, the venue's print spec (size, colour profile, bleed, marks, fonts, filename), project links. Fix the sheet and the 1 px = 1 mm rule.

PLACEHOLDERS.md

2Styleboard

~6 identities as the same real fragment; "more styles"; the register correction ("academic, multi-column, clean, not superficial"). User picks.

3Layout candidates

Ranked space allocations as dotted wireframes. User picks one and prunes: one solid bar, blocks dropped or fused, sub-results stay sub-results.

Resolutions and frame counts differ across methods. Find the evalset ↔ video alignment by image match; verify shared cameras by compositing.

A2Render tiles

Frame grids by normalised position and fractional crop, tile size from the container, unlabelled — labels stay live text, vector in print.

E1Print wrap

build/print.py

E2Ghostscript

CMYK through the venue ICC, every font outlined, TrimBox / BleedBox / ArtBox and an OutputIntent from a pdfmark prologue, FitPage to the exact trim.

build/prologue.psbuild/export_pdf.sh

E3Verify from the bytes

Box sizes in mm, zero embedded fonts, zero DeviceRGB, the intent — then rasterised corners for marks and real glyphs, ink coverage, a resolution audit.
