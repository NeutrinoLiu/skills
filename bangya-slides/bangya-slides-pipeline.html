bangya-slides pipeline

How a talk becomes an HTML slider deck, across parallel sessions. Markdown files are the coordination bus: questions_roundN.md citations.md assets.md progress.md feedback.md — chat stays terse ("done", "check feedback.md").

Main session · content & build

1Brief & sources

Talk outline, schedule, audience, tone rules ("no ad-speak").

2Q&A rounds

Questions with recommended answers; user answers in place. Background research subagents deep-read every cited paper.

questions_round1–3.mdcitations.md

3Talk script

Fine-grained plain-English script with [ASSET] placeholders.

experttalk_v2.md

4Wireframes

Scratchy layout HTML: content blocks, media-placeholder boxes, animation notes. One idea per page; view-as-a-whole stitch script.

slides_layout/

5Build the deck

Section fragments + shared CSS + slider engine + build script → one-slide-at-a-time deck with fullscreen, citation footers, live 3D embeds.

slides/deck.htmlprogress.md

6Render-check

Headless-screenshot every slide, inspect, fix, re-render. De-AI phrasing pass at the end.

⟳ repeat

7Feedback rounds

User writes numbered items; every item implemented, re-rendered, and logged. Leftovers become owned placeholders.

feedback.md
Style session · parallel

B1Styleboard

~6 candidate directions, each as the same two real 16:9 mini-slides — a fair side-by-side. Style is negotiated with the user, never assumed.

B2Converge

User picks and refines: typeface swaps, weight tuning, mixing candidates.

B3Template

Tokens, type scale, grounds, every slide archetype, reusable chrome with live tuning sliders. Choice saved to memory.

_claude_tmp/*_template.html
template ⇢ feeds Build (5)
Asset sessions · parallel

C1Collection subagents

Images, paper figures (from arXiv source tarballs), logos — verified on download. Non-fetchables listed for the user.

assets.mdassets/collected/

C2Burn-down

Videos via yt-dlp with client fallbacks, ffprobe-verified; image-gen via the user's endpoint; cropping user screenshots.

C3Human handoff

"What can I do on my side" list: logins, screenshots, brand assets → dropped into assets/manual/.
