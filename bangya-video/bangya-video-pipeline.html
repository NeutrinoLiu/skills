bangya-video pipeline

How a paper becomes a five-minute narrated video. One source file, build/cutdata.py, holds every cut's slide and script; deck.html is both the checkpoint the user approves and the frame the renderer screenshots.

Cuts in markdown → HTML deck with time and script per cut → assets and TTS → assemble. Set by the user in the first message.

3Deck checkpoint

Every cut as a 1920 × 1000 frame with its hold and script beside it, 480p toggle. Decisions taken here: TTS voice, captions, cuts to rebuild.

4Assemble

Loop the PNG, overlay each clip into its probed box, burn the one-line caption strip from an ASS, concat, two-pass loudnorm, mux. Two encoders, not four.
